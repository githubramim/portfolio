## 🔧 Customization Quick Guide

### Change Name (1 minute)
**File**: index.html, Line 17
```html
<i class="fas fa-code"></i> Your Name Here
```

### Change Phone (1 minute)
**File**: index.html, Multiple locations
```html
<a href="tel:+8801234567890">
```

